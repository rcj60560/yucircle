# 羽圈 · 路线图

## 产品方向

羽球圈 = **独家整合的羽毛球信息**（让用户先因为内容留下来）+ **球友社区**（发声 / 讨论 / 分享）。

两条轨道**并行推进**；设计上一条一条 brainstorm，实现可并行。

---

## 轨道

### Track A — 羽联信息（内容抓手）
- 男单 / 女单 / 男双 / 女双 / 混双 **世界排名**
- **世界巡回赛**赛程（近期 / 往期）
- 展示形式：原生 or WebView（待定）
- 数据来源：~~现成 git 库~~（已探针：无活库）→ **自建低频 Python 爬虫**（进 ky/tools 工具箱）
- 状态：✅ 已交付 + 两轮增强（2026-08-18/19：世锦赛收录/世界排名换源/本周赛况·当日比分·得分曲线·日期回看/服务端落盘子系统）— 交接见 `doc/2026-08-19-BWF增强与落盘交付总结.md`；数据管道：本地 MySQL（yu-server）为主，GitHub raw 为 release 兜底，每周 `python run_all.py --publish` 更新内置资产

### Track B — 社区（球友发声）
- 发帖 / 评论 / 回复 / 删除 / 点赞（取消点赞）
- 帖子分享：**先预留**（个人开发，企业资质后续再补）
- 账号：**mock 优先**（手机验证码登录，后续接真实短信）
- 后端：帖子 / 评论 / 点赞 API 已有
- 方向演进（2026-08-19 脑暴）：资讯创新（BWF 内容×数据底座）+ 虎扑式社区（讨论/投票/热议），地方性暂缓；候选与缺口见 `doc/2026-08-19-TrackB社区与资讯创新_脑暴记录.md`
- 状态：⏳ 脑暴暂停于"v1 优先级"决策 → 下次从该文档 §5 接续
