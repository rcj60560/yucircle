## 1. 项目概况

### 基本信息

| 项 | 内容 |
|-----|------|
| **项目名称** | 羽圈 (YuCircle) |
| **项目描述** | 垂直于羽毛球爱好者的社交平台 + 资讯应用 |
| **目标用户** | 打羽毛球的爱好者、专业运动员 |
| **主要功能** | 社区论坛 + 球馆俱乐部大厅系统 |
| **技术栈** | Flutter / Spring Boot + MySQL |

### 核心价值定位

**解决的痛点**:
- 打羽毛球的社群粘性高，但缺乏交流平台
- 现有平台内容广泛，缺乏垂直深度
- 打球不爽时无处申诉/举报

**解决方案**:
- 专业的社区论坛（类似虎扑社区）
- 聚焦羽毛球内容，深度运营
- 支持用户举报、审核机制
- 球馆俱乐部活动大厅系统

**核心 API 端点**:
- ✅ `GET /api/venues` - 获取球馆列表
- ✅ `GET /api/clubs/venue/{venueId}` - 获取俱乐部列表
- ✅ `POST /api/activities/{id}/enter` - 进入大厅
- ✅ `GET /api/activities/{id}/lobby` - 大厅快照 (核心端点)
- ✅ `POST /api/activities/{id}/ping` - 心跳保活
- ✅ `POST /api/activities/{id}/reserve` - 占坑
- ✅ `DELETE /api/activities/{id}/reserve` - 取消占坑
- ✅ `POST /api/activities/{id}/confirm` - 确认参加
- ✅ `POST /api/activities/{id}/messages` - 发送聊天消息
- ✅ `POST /api/activities/{id}/leave` - 离开大厅
- ✅ `GET /api/broadcasts/active` - 获取活跃广播
- ✅ `POST /api/broadcasts/clubs/{clubId}` - 发送广播

**关键业务逻辑**:
- ✅ JWT Token 身份验证
- ✅ 场地预订流程 (reserved → confirmed → locked)
- ✅ 消息60秒速率限制
- ✅ 自动清理任务 (presence/slot/message/broadcast)
- ✅ 俱乐部实时统计 (todayActivityCount, onlineCount)

## 9. 问题排查

### Q: 前端连接后端超时?

**检查清单**:
1. 后端是否已启动 (`http://192.168.13.80:8080`)
2. 防火墙是否开放 8080 端口
3. `app_config.dart` 中的 `apiBaseUrl` 是否正确
4. 真机测试时使用局域网 IP (非 localhost)

### Q: Mock 模式和真实模式如何切换?

```dart
// lib/config/app_config.dart
static const bool mockMode = true;   // Mock 模式
static const bool mockMode = false;  // 真实模式
```

### Q: 活动大厅轮询不工作?

**排查步骤**:
1. 检查 `ActivityLobbyPage` 中的 Timer 是否正确启动
2. 检查 `/activities/{id}/ping` API 是否正常
3. 检查 JWT Token 是否有效
4. 查看控制台是否有错误日志

### Q: 图片上传失败?

**排查步骤**:
1. 检查后端 `/uploads/` 目录权限
2. 检查文件大小限制 (< 5MB)
3. 检查文件类型限制 (jpg, png, gif)

### Q: 热重载失效?

```bash
# 按 R 完整热启动
flutter run

# 或重新运行
flutter clean
flutter pub get
flutter run
```
