## 🔄 迁移步骤

### 步骤 1: 导入新组件库
在需要使用的页面顶部添加:
```dart
import '../widgets/common_components.dart';
```

### 步骤 2: 替换按钮
**旧代码:**
```dart
ElevatedButton(
  onPressed: () {},
  child: Text('登录'),
)
```

**新代码 (自动蓝色):**
```dart
PrimaryButton(
  label: '登录',
  onPressed: () {},
)
```

或者使用 Flutter 自带的 (会自动使用新主题的蓝色):
```dart
ElevatedButton(
  onPressed: () {},
  child: Text('登录'),  // 自动蓝色，因为主题已更新
)
```

### 步骤 3: 替换卡片
**旧代码:**
```dart
Card(
  child: Padding(
    padding: EdgeInsets.all(16),
    child: ...,
  ),
)
```

**新代码:**
```dart
PrimaryCard(
  padding: EdgeInsets.all(16),
  child: ...,
)
```

### 步骤 4: 替换输入框
**旧代码:**
```dart
TextFormField(
  decoration: InputDecoration(
    hintText: '请输入...',
  ),
)
```

**新代码:**
```dart
PrimaryTextField(
  label: '标签',
  hint: '请输入...',
  controller: controller,
)
```

### 步骤 5: 处理硬编码颜色
**搜索所有硬编码颜色:**
```
Color(0xFF58CC02)  → AppTheme.primary (蓝)
Color(0xFF4CAF00)  → AppTheme.primaryDark (深蓝)
Color(0xFFFFFFFF)  → AppTheme.surface (白)
Color(0xFFF7F7F7)  → AppTheme.background (蓝灰)
color: Colors.green → 检查是否应改为 AppTheme.primary
```

## 💡 技巧与建议

### 1. 利用 Material 3 主题
大部分情况下，只需更新 `theme.dart`，页面代码不需要改。

```dart
// 这些会自动使用主题颜色
ElevatedButton(...)           // 自动蓝色
TextButton(...)               // 自动蓝色
Icon(Icons.favorite)          // 需要手动指定颜色
Text(...)                     // 自动应用主题字体
```

### 2. 逐个页面验证
修改一个页面后，立即运行:
```bash
flutter run
```

使用 Hot Reload (Ctrl+S) 快速查看效果。

### 3. 搜索所有颜色引用
打开 VS Code 搜索面板 (Ctrl+Shift+F):
```
搜索: Colors\.|color:|Color\(
正则表达式: 打开
```
这会找出所有颜色引用。

### 4. 保持一致性
- 所有蓝色按钮都用 `AppTheme.primary`
- 所有成功状态都用 `AppTheme.accent` (绿)
- 所有错误都用 `AppTheme.danger` (红)

## ❓ 常见问题

**Q: 改了主题后，所有按钮都自动变蓝了吗？**
A: 是的！因为主题系统已经更新，任何使用 `ElevatedButton`, `TextButton` 等 Material 组件都会自动应用新的蓝色主题。

**Q: 我之前用的 `Colors.green` 怎么办？**
A: 改成 `AppTheme.primary` (蓝) 或 `AppTheme.accent` (绿，仅限成功状态)。

**Q: 我想保留某个地方的绿色怎么办？**
A: 只有"成功"状态才保持绿色，改成 `AppTheme.accent` (#4CAF50)。其他都改蓝色。

**Q: 我想为某个按钮自定义蓝色的深浅怎么办？**
A: 使用 `AppTheme.primary` (蓝), `AppTheme.primaryDark` (深蓝), `AppTheme.primaryLight` (浅蓝)。

**Q: 改完后需要重新编译吗？**
A: 需要。建议删除 build 文件夹后重新编译:
```bash
flutter clean
flutter pub get
flutter run
```
