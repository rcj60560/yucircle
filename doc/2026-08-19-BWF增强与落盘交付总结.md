## 4. 服务端（yucircle-server）— BWF 数据落盘子系统

Spring Boot 3 + MyBatis-Plus + MySQL（本地 yucircle 库），7 提交 `fb6662c..c1bb50c`；架构文档 `doc/06_BWF数据落盘_架构设计.md`、进度 `doc/07_BWF数据落盘_开发进度.md`（含全部坑位记录）。

- **5 张表**：`bwf_tournament`（uk tmt_id）/ `bwf_ranking_entry`（uk 期+单项+名次）/ `bwf_match`（uk tmt+场次码，含 order_no 官方顺序）/ `bwf_match_game` / `bwf_match_point`（逐分=累计得分；v0 只抓 Grade 1 大赛，`bwf.sync.point-sync-levels=major`）
- **代码分层**：`util/BwfExtranetClient`（5 端点、fetch 可注入）+ `util/BwfParser`（纯解析，5 组单测）+ `service/BwfSyncService`（幂等批量 upsert + 查询）+ `controller/BwfController` + `task/BwfSyncTasks`
- **接口**：GET `/api/bwf/rankings|rankings/history|schedule|matches|match-detail`；POST `/api/bwf/admin/refresh?scope=all|rankings|schedule|matches`（手动重抓=调试主入口）；GET `/api/bwf/app/rankings|schedule`（资产同构，App 直连）
- **定时**：周一 10:00 排名+赛程；每日 22:00 当日赛果（级别达标自动带逐分）；`bwf.sync.enabled` 总开关
- **验证**：gradle build（编译+测试）全绿

## 5. 联调流程（已跑通的设计）

```
启动 MySQL + server → POST /api/bwf/admin/refresh?scope=all → 数据落库
→ 浏览器开 /api/bwf/app/rankings 核对，或 App debug 直接看页面（远端自动连 localhost）
→ 数据不对：改代码 → 重启 server → 再调 refresh（幂等覆盖，不留脏数据）
→ 查表分析：直连 MySQL 查 bwf_* 五张表（排名走势/逐分曲线 SQL 直出）
```
