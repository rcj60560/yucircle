### 待后端API实现后的对接任务

当后端 Phase 4 API 准备好后，需要进行以下修改：

1. **在 `lib/services/api_client.dart` 中新增 API 调用方法：**
   - 获取球馆列表
   - 获取俱乐部列表
   - 创建/进入活动
   - 获取大厅快照（大厅数据）
   - 发送心跳 ping（30秒保活）
   - 占坑/取消坑位/确认参加
   - 获取/发送聊天消息
   - 获取/发送广播

2. **在各页面中替换 Mock 数据为真实 API 调用：**
   - `VenueListPage` → 调用获取球馆列表 API
   - `ClubListPage` → 调用获取俱乐部列表 API
   - `ActivityLobbyPage` → 集成轮询大厅快照 API（2秒一次）

3. **在 `ActivityLobbyPage` 中实现定时器：**
   - 页面初始化时启动 2 秒轮询定时器
   - 每次收到大厅快照更新 UI（坑位、在线人数、消息、广播）
   - 每 30 秒发送 ping 心跳
   - 页面销毁时关闭定时器并调用离开大厅 API

4. **新增 GetX Controller（可选但推荐）：**
   - `lib/providers/activity_lobby_controller.dart`
   - 管理大厅状态（轮询、心跳、占坑等）
   - 减少页面复杂度
